## Описание работы

В данной лабораторной работе реализована функция формирования хеша блока с использованием алгоритма **SHA-256** из библиотеки `hashlib` языка Python.

Основной задачей программы является демонстрация принципа связывания данных через хеширование, который используется в технологиях блокчейна. Для этого берутся данные текущего блока и хеш предыдущего блока, после чего они объединяются в одну строку. Полученная строка преобразуется в байтовый формат и передается в алгоритм SHA-256 для вычисления уникального криптографического хеша.

В программе реализована функция `sign_block()`, которая принимает два параметра:

* `prev_hash` это хеш предыдущего блока;
* `data` это данные текущего блока.

Функция выполняет следующие действия:

1. Объединяет хеш предыдущего блока и данные текущего блока в одну строку.
2. Преобразует полученную строку в последовательность байтов с кодировкой UTF-8.
3. Вычисляет SHA-256 хеш с помощью модуля `hashlib`.
4. Возвращает результат в шестнадцатеричном формате.

После определения функции в программе приведен пример ее использования. Для тестирования задаются значения:

* предыдущий хеш: `"abc"`;
* данные блока: `"123"`.

Затем вызывается функция `sign_block()`, и на экран выводятся:

* исходный хеш предыдущего блока;
* данные текущего блока;
* объединенная строка;
* вычисленный SHA-256 хеш.

## Результат работы

В ходе выполнения лабораторной работы была изучена работа криптографической хеш-функции SHA-256 и реализован простой механизм формирования хеша блока на основе данных и хеша предыдущего блока. Полученный результат демонстрирует принцип обеспечения целостности данных и связи между блоками, который используется в блокчейн-системах.
